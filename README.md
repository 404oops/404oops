## Hi! I'm Filip, aka 404oops.

I maintain the backend at [Puter](https://github.com/HeyPuter/puter) and build open-source desktop apps, developer tools, and utilities for hardware.

### What I'm working on

At Puter, much of my current work is on **AI services and backend reliability**: integrating providers and models, keeping model catalogs and pricing current, and improving routing, billing, streaming, cancellation, and error handling.

Outside of that, I'm building **native desktop software in Rust with GPUI**:

- [Vamprowser](https://github.com/404oops/vamprowser) — a macOS browser with WebKit for pages and a native GPUI interface.
- [Vampir](https://github.com/404oops/vampir) — a GPUI widget toolkit with shared styling, animation, text input, menus, and other controls.
- [Immersion](https://github.com/404oops/immersion) — automatic version history for creative projects, with a visual graph for exploring and restoring earlier versions.
- [SPAWN Universal](https://github.com/404oops/spawn-universal) — a native configurator for SPAWN Hall-effect keyboards, built around a reimplementation of their HID protocol.
- [Macropad](https://github.com/404oops/Macropad) — macOS software that turns a USB numeric keypad into a macro pad.

I also work on music and audio tools, including [Musique+](https://github.com/404oops/musiqueplus), a Discord bot for music metadata, previews, and links across streaming services, and [Audinspect](https://github.com/404oops/Audinspect), an audio-file inspector. Other projects include [ESPWR](https://github.com/404oops/ESPWR), an ESP32 remote power controller, and [virt-manager-web](https://github.com/404oops/virt-manager-web), browser access to virt-manager in Docker.

### Tools I use

My current work centers on **Rust**, **JavaScript/TypeScript**, **GPUI**, and **Docker**. I also work with Python, C/C++, C#, Electron, and React.
